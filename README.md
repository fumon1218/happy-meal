# 🍱 행복한 급식

우리 반 친구들의 **음식 주문을 받아 급식을 배달**하는 특수교육용 학습 놀이 (옥쌤의 즐거운 교실 자매 앱).

1. **주문 받기** – 친구의 주문을 그림과 소리로 확인해요.
2. **담기** – 풍선 터트리기 · 급식 낚시 · 새 잡기 · 급식 뽑기 중 하나로 음식을 식판에 담아요 (섞어서도 가능).
3. **배달** – 완성한 식판을 친구 자리까지 가져가요.
4. **도감** – 배달한 음식(127종)이 도감에 모여요.
5. **학습지 인쇄** – 주문 고르기 · 식판 오려 붙이기 · 그림과 이름 잇기 · 배달 자리 찾기 (정답지 포함, A4).

* 시간 제한과 탈락이 없어요. 틀리면 부드럽게 돌려보내고, 1~2단계·느리게·버튼 한 번 모드에서는 알맞은 것이 반짝여요.
* 단계 1~5: 한 가지 → 개수 → 자리 이름표 → 못 먹는 음식·자리 위치 → 여러 친구 주문.
* 친구 이름과 못 먹는 음식(달걀·우유·생선·매운 음식)은 설정에서 바꿀 수 있고, **이 기기에만** 저장돼요.

## 그림 넣기
`img/` 아래에 규칙 이름으로 넣으면 코드를 고치지 않아도 자동으로 쓰여요. 없으면 이모지로 보여요.
`img/food/<id>.webp` · `img/friend/<친구id>.webp`(`f0`~`f5`, `_happy` 붙이면 웃는 얼굴) · `img/ui/{tray,balloon,hook,bird,gacha,desk,logo}.webp` · `img/bg/{home,balloon,fishing,birds,gacha,class}.webp`

## 개발
* `python3 -m http.server` 후 `index.html?dev=fast` (빠른 모드)
* `node scripts/smoke-test.mjs` 데이터 점검 · `node scripts/bot.js` 5놀이×5단계 자동 플레이(playwright 필요)
* 파일을 바꾸면 `python3 scripts/build_sw.py` 로 오프라인 캐시 목록을 다시 만들어요.
